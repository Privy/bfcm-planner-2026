# Privy BFCM Flows Checklist

Source: BFCM_Flows_Checklist_vFINAL.xlsx. 15 automated flows to build, update, or pause. Priority 1 = must be done before the first BFCM send. Reference these IDs (F01-F15) in the plan.

> **Plan window note:** the plan ends Fri Dec 4, 2026 (the Friday after Cyber Monday). Where an item below mentions December, January, holiday cutoffs, or gift guides, plan only the in-window part (for example the resume date for a paused flow) and list the rest under "Hand off to your holiday plan."


## List Growth & Onboarding

### F01 - Welcome Series (Email) (Priority 1)
- **Trigger:** New email subscriber
- **Definition:** Multi-step intro to the brand sent to anyone who joins the email list.
- **BFCM adjustment:** Swap the evergreen welcome offer for a BFCM teaser or the live deal. Shorten delays so new subscribers see the offer before it ends. Add a final 'deals are live' step during the sale window.
- **Content / key messages:** Who you are and why it matters, bestsellers with social proof, then the offer. During BFCM: lead with the deal and a deadline.

### F02 - Welcome Series (SMS) (Priority 1)
- **Trigger:** New SMS subscriber
- **Definition:** Short SMS sequence confirming opt-in and delivering the signup incentive.
- **BFCM adjustment:** Replace the standard incentive code with the BFCM offer so codes don't stack. Add a 'sale is live' SMS on launch day for anyone who joined in the last 30 days.
- **Content / key messages:** Confirm opt-in, deliver the code in one tap, set expectations for BFCM alerts.

### F03 - BFCM Early Access Signup (Priority 1)
- **Trigger:** Joins early access list or SMS keyword
- **Definition:** Confirms the early-access signup and delivers the head start when deals go live.
- **BFCM adjustment:** Net-new flow for the season. Build the confirmation, a 'tomorrow' reminder, and the early-access drop with a unique code or link.
- **Content / key messages:** "You're on the list." Countdown reminder, then the deal drop with a private link. Tone: insider, not sale-y.

### F04 - Popup Coupon Reminder (Priority 2)
- **Trigger:** Signed up on a popup, no order in 24 hours
- **Definition:** Follows up with visitors who claimed a popup or spin-to-win offer but have not purchased yet.
- **BFCM adjustment:** Update copy and code to match the BFCM offer. Tighten the delay to a few hours since sale windows are short.
- **Content / key messages:** "Your code is waiting." Restate the offer and expiry, link straight to bestsellers.

## Conversion & Recovery

### F05 - Abandoned Cart (Priority 1)
- **Trigger:** Added to cart or started checkout, no order
- **Definition:** Reminds shoppers to finish checkout, usually 2-3 touches over 24-48 hours.
- **BFCM adjustment:** Shorten the first delay to 30-60 minutes. Remove or reduce the standalone cart discount while a sitewide sale runs to avoid stacking. Add an SMS step. Sale wording in the flow goes in when the public sale starts and comes out when it ends, as separate dated tasks. A "last chance" message belongs in the send calendar as a campaign, since flows send a set time after each person's trigger, never on a date.
- **Content / key messages:** "Your cart just went on sale" or "Still thinking it over?" Show the items, the savings, and the deadline. One-tap back to cart.

### F06 - Browse Abandonment (Priority 2)
- **Trigger:** Viewed product, no add to cart
- **Definition:** Nudges product viewers back with the item they looked at.
- **BFCM adjustment:** Point out that the viewed category is included in BFCM deals. Increase frequency cap during the sale window; reset after Cyber Monday.
- **Content / key messages:** The product they viewed, key benefits, reviews, and the BFCM price. Soft tone; this is a nudge, not a chase.
- **Channel:** Email. Never recommend adding SMS here: browse is too far up the funnel for SMS. If the merchant already has an SMS step, leave it as is.

### F07 - Back In Stock (Priority 1)
- **Trigger:** Requested item restocked
- **Definition:** Notifies waitlisted shoppers the moment an item is available again.
- **BFCM adjustment:** Mention BFCM pricing if the item is included. Send SMS first, then email; these shoppers move fast.
- **Content / key messages:** "It's back, and it's on sale." Urgency around limited quantity; one clear buy button.

## Post-Purchase

### F08 - Order Confirmation / Thank You (Priority 1)
- **Trigger:** Order placed
- **Definition:** Confirms the order and sets delivery expectations.
- **BFCM adjustment:** Add shipping timelines and holiday cutoffs. Suppress discount CTAs for 14 days post-purchase. Keep any cross-sell to gifting or add-ons.
- **Content / key messages:** Thank you, what happens next, when to expect it. Optional: 'Shopping for someone else?' gift guide link.

### F09 - Post-Purchase Cross-Sell (Priority 2)
- **Trigger:** Order placed, 3-7 days later
- **Definition:** Recommends complementary products after the first order.
- **BFCM adjustment:** Move the delay earlier during BFCM so the recommendation arrives while deals are still live. Exclude items already in the order.
- **Content / key messages:** "Goes great with your [product]." One or two pairings, BFCM price, deadline.

### F10 - Review Request (Priority 3)
- **Trigger:** Order delivered, 7-14 days later
- **Definition:** Asks customers to leave a review.
- **BFCM adjustment:** Pause or extend the delay during BFCM week to reduce inbox noise. Resume in December once orders have landed.
- **Content / key messages:** Simple ask, one-tap star rating, thank-you incentive if you use one.

### F11 - Replenishment (Priority 2)
- **Trigger:** X days after buying a consumable
- **Definition:** Reminds customers to reorder before they run out.
- **BFCM adjustment:** If a reorder window lands in BFCM, promote a stock-up bundle at the sale price instead of a single reorder.
- **Content / key messages:** "Running low? Stock up and save." Multi-pack or subscription upgrade with the BFCM discount.

### F12 - Post-BFCM New Customer Nurture (Priority 2)
- **Trigger:** First order during BFCM window
- **Definition:** Turns deal-driven first-time buyers into repeat customers.
- **BFCM adjustment:** Net-new flow. Build now, goes live after Cyber Monday. Delay first message until after delivery.
- **Content / key messages:** Brand story, how to get the most from what they bought, then a second-purchase offer in January. No hard sell in the first two messages.

## Retention & Lifecycle

### F13 - VIP Tier Entry (Priority 1)
- **Trigger:** Reaches VIP threshold (orders or spend)
- **Definition:** Welcomes customers into the top tier.
- **BFCM adjustment:** Grant BFCM early access automatically on entry. Make sure the threshold check runs before the Early Access drop.
- **Content / key messages:** "Welcome to the inside." What VIP gets them, then the early-access link.

### F14 - Win-Back (Priority 1)
- **Trigger:** No order in 90+ days
- **Definition:** Re-engages lapsed customers with an offer.
- **BFCM adjustment:** Pause during the BFCM send window so lapsed customers don't get a win-back offer and a BFCM campaign on the same day, or reroute them into the BFCM sequence.
- **Content / key messages:** "It's been a while" plus what's new. During BFCM, the campaign carries the offer; the flow stays quiet.

### F15 - Birthday / Anniversary (Priority 3)
- **Trigger:** Date-based
- **Definition:** Sends a personal offer on a birthday or signup anniversary.
- **BFCM adjustment:** Pause for BFCM week or make sure the birthday code doesn't stack with sale pricing. Consider a 'use it after the sale' extension.
- **Content / key messages:** Personal, warm, no sale language. Extend the code so it doesn't expire during the noise.
